## 개요

데이터패브릭 기술을 적용한 서비스 명칭은 **Open VDAP**이며, 본 저장소는 Open VDAP을 구성하는 요소 중 **화면 계층**입니다.

데이터 검색과 카탈로그 조회, 융합 뷰 구성, 표준 메타데이터 관리, 데이터 관계 시각화 화면을 제공합니다.

## 데이터 패브릭

'데이터 패브릭(Data Fabric)' 은 다양한 이기종 시스템에 분산되어 저장된 데이터에 대한 통합된 접근과 활용을 위한 솔루션으로 가트너에서 2022년 이후 12대 전략기술 중 하나로 선정 하였습니다.
즉, "다양한 시스템에 분산된 대규모 데이터에 대한 통합적인 접근과 공유를 위한 정보네트워크 체계" 라 정의할 수 있습니다.

### 구성요소

**1. 확장된 데이터 카탈로그**

‘확장된 데이터 카탈로그’를 통한 분산된 데이터에 대한 통합적인 접근 기반 제공 - 데이터 패브릭을 실체화하기 위한 가장 핵심 요소

**2. 데이터포털**

‘데이터 포털’을 통해 사용자들이 데이터 카탈로그의 메타데이터를 쉽고 빠르게 검색하고 요청할 수 있는 데이터 접근 및 분석 활용 체계 제공

**3. 데이터 준비 및 전달**

검색-요청된 다양한 형태의 분산된 데이터 저장소에서 데이터를 추출-통합하여 전달하는 ‘데이터 준비 및 전달 체계’

## 기능

- 데이터의 저장 위치 및 형태를 가상화 하는 기술 
- 통합 연계를 위한 메타 데이터 기술 
- 데이터 상태 모니터링 및 관리 기술 
- 추상화된 데이터 스키마를 탐색하는 기능 
- 데이터 뷰 생성 시 다중 데이터간 융합 추천 기능
- 머신러닝 기반 데이터 카탈로그 생성 기술 
- 카테고리 기반 연관 데이터 관계 시각화 기능 
- 통합 데이터 뷰 융합/정제/변환 기능 
- 데이터 처리 과정을 관리하기 위한 데이터 워크플로우 기능
- 유의미한 데이터 조합 및 연관 규칙 시각화 기능 
- 데이터 패브릭 포털
- 데이터 품질관리를 위한 지표 생성 기술 
- 표준 메타데이터 관리 및 표준 준수 판정
- 관계 데이터 간 유사 속성 관계 시각화
- 분석 복합관계 시각화 통합 기술

## 구성

```
project/
├── portal/      데이터 패브릭 포털 (2,166파일)
│   ├── src/                 Spring Boot 백엔드
│   ├── frontend/            Nuxt 3 프런트엔드
│   ├── publishing/          화면 퍼블리싱 산출물
│   ├── config_templates/    설정 템플릿
│   ├── docs/                프로세스 흐름 문서
│   └── docker/
├── ovp/         메타데이터 조회 화면 (778파일)
│   ├── server/              BFF 서버
│   └── frontend/
└── keycloak/    인증 연동 (441파일)
```

`portal`은 데이터 검색·카탈로그·융합 뷰·표준 메타데이터·모니터링 화면을 제공합니다. `ovp`는 메타데이터 조회 화면을, `keycloak`은 인증 연동을 담당합니다.

## 설정

`project/portal/config_templates/application-sample.yml`을 복사해 사용합니다.

```bash
cp project/portal/config_templates/application-sample.yml \\
   project/portal/src/main/resources/application-local.yml
```

연동 대상(데이터베이스, 객체 저장소, 질의 엔진, 카탈로그 API, 추천, 논리적 데이터 통합)의 주소와 인증 정보를 환경에 맞게 채웁니다.

비밀값은 Jasypt로 암호화해 `ENC(...)` 형태로 기록합니다. **평문 비밀값을 저장소에 기록하지 않습니다.**

## 빌드와 실행

```bash
# 백엔드
cd project/portal
mvn clean package

# 프런트엔드
cd frontend/nuxt-project
npm ci
npm run build
```

컨테이너로 빌드하는 경우입니다.

```bash
cd project/portal
./docker/build.sh
```
